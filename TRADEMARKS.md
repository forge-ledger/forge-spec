# Trademarks and branding

The licenses in this repository (CC0 / CC-BY) **do not** grant trademark rights.

## Permitted

- mention the specification's name in factual descriptions, for example
  "compatible with Forge Ledger Format v1";
- state in a fork or implementation that it follows this specification;
- quote the name in academic, journalistic, or comparative writing.

## Not permitted

- use the project's name or logo to imply that your fork, product, or service is
  officially endorsed;
- use a name or icon likely to be confused with the official repository;
- imply that your implementation passes this specification without a compatibility
  statement.

## Naming forks

A fork should use a different name and state clearly in its README:

- which version it is based on;
- how it relates to this specification;
- that it is not an official release.

## Contact

If you are unsure whether a use is appropriate, open an issue to ask first.
