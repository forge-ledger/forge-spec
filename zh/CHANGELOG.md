# 变更记录

本文件只记录**规范**的变化。参考实现的变化不在本仓库的记录范围内。

## 1.0.0

首个公开版本。定义：

- 三层数据模型：`sources/`（只读原料）、`assets/`（可写资产）、`index/`（可重建索引）。
- 四种资产类型：`decision`、`state`、`event`、`rule`，以及各自的写规则、必填字段与必填章节。
- front-matter v1 字段全集与 JSON Schema。
- ID 形状：`<类型前缀>_<26 位 Crockford base32>`。
- 出处 span 语法：`scheme://target#anchor`，四种锚点（`#h:` / `#t:` / `#k:` / `#L`）。
- 新鲜度只挂在 `state` 上。
- 一套零依赖的示例校验器（`validate.mjs`）。

## 版本策略

版本分两层，含义不同：

- **格式版本**：`../schema/taxonomy.yaml` 里的整数（当前 `1`），也写在每条资产的
  `schema_version` 里。它决定文件能不能被读懂。
- **发布版本**：`VERSION` 里的 `x.y.z`（当前 `1.0.0`），对应标签
  `spec-vX.Y.Z`。它只标记规范的发布批次。

两层必须对齐：发布版本的主版本号等于格式版本（`1.0.0` ↔ 格式 v1），
`validate.mjs` 会校验。不兼容的变化（删字段、改语义、改 ID 形状）必须升格式版本，
并提供迁移说明；兼容的澄清与示例增补只更新文档，不升格式版本。
