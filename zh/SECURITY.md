# 安全策略

## 报告安全问题

请**不要**在公开 issue 里报告安全问题。

请使用 GitHub 的私下报告通道：
`Security` → `Advisories` → `Report a vulnerability`
（或仓库页面的 `/security/advisories/new`）。

也可以发送到 `security@forge-ledger.com`。请不要把敏感细节写进公开 issue。

报告中请包含：

- 受影响的规范版本；
- 复现所需的最小合成示例；
- 你预期发生什么、实际发生什么；
- 是否已经在某个实现里观察到。

**不要在报告里附带真实会话或客户数据。** 如果需要示例，请使用合成数据。

## 响应承诺

- **48 小时内**确认收到；
- 7 天内给出初步判断（是否属于安全问题、影响范围）；
- 修复或缓解方案确定后，与报告者协调披露时间。

## 范围

本仓库是规范，不是可执行服务。以下属于范围：

- 规范本身允许了会导致数据丢失、出处伪造或静默覆盖的设计；
- 校验器（`validate.mjs`）会把坏输入判成通过；
- 示例或文档引导读者把真实数据写进仓库。

以下通常不属于范围：

- 某个第三方实现的漏洞（请报告给该实现）；
- 与规范无关的 GitHub 平台问题。

## 支持版本

当前支持 **v1**。旧版本只在迁移指导范围内提供说明。
