# 行为准则

## 我们的承诺

为了让每个人都能在没有骚扰的环境里参与，我们承诺：无论年龄、体型、残障、
性别认同与表达、经验水平、教育、社会经济地位、国籍、外貌、种族、宗教或性取向，
参与者都不会受到骚扰。

## 期望行为

- 使用欢迎与包容的语言；
- 尊重不同的观点与经验；
- 优雅地接受建设性批评；
- 关注对社区最有利的事；
- 对其他社区成员保持同理心。

## 不可接受的行为

- 性化的语言或图像，以及不受欢迎的性关注；
- 挑衅、侮辱、贬损的评论，以及人身或政治攻击；
- 公开或私下的骚扰；
- 未经明确许可发布他人的私人信息；
- 在专业场合中其他合理认定为不当的行为。

## 执行

维护者负责解释与执行本准则。维护者可以删除、编辑或拒绝不符合本准则的
评论、提交、代码与 issue。

报告请发送到 `conduct@forge-ledger.com`，或通过 GitHub 私下联系维护者。
所有投诉都会被审查与调查，并按情况作出必要且适当的回应。
维护者有义务对报告者的情况保密。

## 归属

本准则改编自 Contributor Covenant 2.1。
