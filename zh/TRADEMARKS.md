# 商标与品牌

本仓库的许可（CC0 / CC-BY）**不包含**商标许可。

## 允许

- 在事实性描述中提及本规范的名字，例如"兼容 Forge Ledger Format v1"；
- 在 fork 或实现中说明它遵循本规范；
- 在学术、新闻或比较性文章中引用名称。

## 不允许

- 使用本项目的名称或标识暗示你的 fork、产品或服务获得官方认可；
- 使用容易与官方仓库混淆的名称或图标；
- 在没有兼容性声明的情况下暗示你的实现通过了本规范。

## fork 的命名

fork 应当使用不同的名称，并在 README 中明确说明：

- 它基于哪个版本；
- 它与本规范的关系；
- 它不是官方发布。
